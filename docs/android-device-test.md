## ۱. آماده‌سازی (یک بار، حدود ۵ دقیقه)

**چرا USB و نه Wi-Fi:** روی `http://192.168.x.x` کروم اندروید صفحه را «امن» حساب نمی‌کند. در آن حالت service worker
(یعنی API ساختگی MSW) ثبت نمی‌شود و Web Share (اشتراک فایل PDF، FE-079) هم غیرفعال است، پس نیمی از سناریوها
غلط شکست می‌خورند. با `adb reverse` گوشی همان `localhost` کامپیوتر را می‌بیند که context امن است.

1. روی گوشی: **Settings → About phone → Build number** را ۷ بار بزنید، بعد **Developer options → USB debugging** را روشن کنید.
2. گوشی را با کابل وصل کنید و «Allow USB debugging» را روی گوشی تأیید کنید.
3. روی کامپیوتر، سرور توسعه را بالا بیاورید:

   ```bash
   pnpm --filter @gold/web dev --port 5173 --strictPort
   ```

4. پورت را به گوشی بدهید (`adb` همراه Android SDK Platform-Tools است):

   ```bash
   adb reverse tcp:5173 tcp:5173
   ```

5. روی گوشی در **Chrome** آدرس `http://localhost:5173` را باز کنید.
6. **برای INP:** روی کامپیوتر در Chrome آدرس `chrome://inspect/#devices` را باز کنید و زیر نام گوشی **inspect** را بزنید.
   در پنل **Performance** بخش **Live metrics** مقدار INP واقعی همان گوشی را حین کار نشان می‌دهد.

**ورود آزمایشی (داده‌ی ساختگی):** ایمیل `owner@example.com` · رمز `password123` · شناسه‌ی فروشگاه `demo`
