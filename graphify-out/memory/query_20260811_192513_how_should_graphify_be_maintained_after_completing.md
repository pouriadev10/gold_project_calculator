# Q: How should Graphify be maintained after completing a project task?

## Answer

Run graphify . --update before handoff to capture code, documentation, and image changes. Save the task summary, principal graph nodes, and executed tests with outcome useful; then run graphify reflect --if-stale at the next session start.
